## Entry

The entry is a single line (at most 200 characters): the one line my AI agent would leave about its human on a rating site. It lives in `entry.txt`.

## How to run

```sh
python3 main.py
```

`main.py` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`).
